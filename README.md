# ☁️ CloudWise - Intelligent Cloud Cost Optimizer

CloudWise is a simple cloud cost optimization application built to practice cloud technologies, backend development, REST APIs, and database management.

The application allows users to manage cloud services, track monthly cloud costs, and view basic cost optimization insights.

---

## 🚀 Features

- Add cloud services
- Store cloud usage information
- View all cloud services
- Calculate total monthly cloud cost
- Identify the highest-cost service
- Basic cloud cost optimization recommendations
